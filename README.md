# DSA Arena

Python-first DSA practice platform with a coding editor, timed challenges, automated tests, and progress tracking.

## Planned stack
- React frontend
- FastAPI backend
- Python challenge runner
- SQLite progress tracking

## Roadmap
- [ ] Python editor and Run Code
- [ ] Public and hidden test cases
- [ ] 15/30/45/60-minute timer
- [ ] Arrays, strings, hash maps, stacks and trees
- [ ] Progress dashboard

> Work in progress. Never run untrusted Python code without sandboxing.
